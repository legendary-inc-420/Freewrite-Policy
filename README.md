# Privacy Policy for FreeWrite AI Chrome Extension

_Last updated: June 2024_

## Overview

FreeWrite AI is a browser extension that helps users write, rephrase, and interact with AI directly from their browser. We are committed to protecting your privacy and ensuring transparency about how your data is handled.

---

## What Data Do We Collect?

**FreeWrite AI does NOT collect, transmit, or sell any personal data.**  
All processing is performed locally in your browser or via the Gemini API using your own API key.

### Specifically:
- **API Key:** Your Gemini API key is stored locally in your browser’s storage. It is never sent to our servers or shared with third parties.
- **User Preferences & Prompts:** Any custom prompts or settings you create are stored locally in your browser.
- **Selected Text & Content:** When you use the extension to process or rephrase text, the content is only used for that session and is not stored or transmitted elsewhere.

---

## Permissions Explained

- **activeTab:** Used to interact with the content of the currently active tab only when you invoke an extension feature. We do not monitor your browsing activity.
- **Host Permissions:** Required to access and process selected text on web pages at your request. No browsing data is collected or stored.
- **Scripting:** Scripts are injected only when you use an extension feature, such as processing selected text. No scripts run automatically or in the background.
- **sidePanel:** Allows the extension to provide a convenient interface alongside any webpage. No browsing data is collected.
- **storage:** Used to save your preferences, API key, and custom prompts locally. No data is sent to external servers.

---

## How Is Your Data Used?

- **Locally:** All data (API key, prompts, preferences) is stored and processed locally in your browser.
- **With Gemini API:** When you use AI features, your text and API key are sent directly to the Gemini API endpoint. We do not have access to this data.

---

## Third-Party Services

- **Gemini API:** All AI processing is performed by the Gemini API using your own API key. Please review [Google’s privacy policy](https://policies.google.com/privacy) for more information.

---

## Data Security

- We do not collect or store any personal data on our servers.
- All sensitive information remains on your device.

---

## Changes to This Policy

We may update this policy from time to time. Any changes will be posted here and reflected in the extension’s update notes.
